# Bitragunta Prasanna Kumar — AI & Engineering Portfolio

> **Cinematic, Full-Viewport Personal Portfolio Landing Page**  
> Recreating the award-winning minimalist aesthetic (basis33 bitmap typography, full-bleed continuous video background, high-contrast monochrome design language) tailored for **Bitragunta Prasanna Kumar**, Computer Science & Engineering Undergraduate (AI & ML) at SRM Institute of Science and Technology.

## 🚀 Live Demo & Key Highlights

- **Single Full-Screen Locked Composition**: `h-screen w-full overflow-hidden bg-black text-white`
- **Dynamic Background Video**: High-definition ambient motion loop streaming from CloudFront CDN
- **Dual-Mode System**:
  - **Prasanna Kumar Mode**: Personalized portfolio showcasing machine learning systems, verified credentials, education, and resume
  - **Adam Roberts Spec Mode**: Exact verbatim template reproduction matching the design reference specification
- **Interactive Modals & Real-Time Simulators**:
  1. **Random Forest Phishing URL Classifier**: Interactive lexical & structural entropy feature extractor
  2. **OpenCV Parking Bay Occupancy Pipeline**: Real-time contour segmentation simulator with Flask API format
  3. **Multiple Linear Regression Pricing Model**: Live property valuation calculator with dynamic feature sliders
  4. **Full-Spectrum Resume Viewer**: Formatted curriculum vitae with one-click print-to-PDF and clipboard copy
  5. **Direct Contact Terminal**: Integrated form with celebratory particle physics feedback

---

## 🛠️ Tech Stack

- **Core**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Typography**: 
  - `Inter` (Google Fonts) — Nav, labels, body copy, and UI text
  - `basis33` (Bitmap/Pixel Monospace) — Brand badges, headline accents, category labels
- **Icons**: `lucide-react`
- **Interactions & FX**: `canvas-confetti`
- **Dev Tools**: ESLint + PostCSS + Autoprefixer
